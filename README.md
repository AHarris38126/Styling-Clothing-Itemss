# Selectors, Webpage Box Model

## Assignment: Clothing Catalog

For this assignment you will create an page to display clothing items for a store.

### Instructions
Link the stylesheet (index.css) to the htnl file (index.html):
- Add a link tag to the top of the html file (index.html)
  - Change value of the 'src' attribute on the link tag to a file-path of the stylesheet.
  
Use the stylesheet to color-code the image borders for the different categories of items.
- Add a style block for the 'shirts' class (.shirts)
  - Use the 'border' property to change the border of the shirts to red
- Add a style block for the 'pants' class (.pants)
  - Use the 'border' property to change the border of the pants to purple
- Add a style block for the 'shoes' class (.shoes)
  - Use the 'border' property to change the border of the shoes to blue


Take a look at Example.png for an idea of how the end result should look.
